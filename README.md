## 📌 درباره پروژه
این پروژه یک سیستم کامل مدیریت کتابخانه دانشگاهی به زبان **Java** و بر پایه اصول شیءگرایی (OOP) است.

### 🌟 ویژگی‌های اصلی پروژه:
- **مدیریت کاربران:** پشتیبانی از دو سطح دانشجو (سقف ۳ جلد) و استاد (سقف ۵ جلد).
- **دسته‌بندی کتاب‌ها (ویژه رقم آخر ۶):** قابلیت دسته‌بندی موضوعی (رمان، علمی، درسی و...).
- **داده‌های اولیه:** ساخت خودکار ۳۶ کتاب و ۳۶ کاربر اولیه بر اساس دو رقم آخر شماره دانشجویی.
- **جستجوی پیشرفته:** امکان جستجو بر اساس عنوان، نویسنده و دسته‌بندی.
- **مرتب‌سازی:** قابلیت مرتب‌سازی الفبایی کتاب‌ها با استفاده از `Comparable`.

---

## 🛠 ساختار کلاس‌ها
- `BookStatus.java`: وضعیت کتاب (Enum)
- `Book.java`: کلاس اطلاعات و وضعیت کتاب
- `Person.java`: کلاس انتزاعی پایه برای کاربران
- `Student.java` & `Professor.java`: کلاس‌های ارث‌بری‌شده
- `Library.java`: کلاس مدیریت و منطق اصلی کتابخانه
- `LibrarySystem.java`: کلاس اصلی اجرا و منوی کنسولی
